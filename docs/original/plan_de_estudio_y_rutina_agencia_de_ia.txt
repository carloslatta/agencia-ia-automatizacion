2. HOJA DE RUTA SEMANAL Y CONTENIDOS TÉCNICOS (3 MESES)
-------------------------------------------------------------------------------

MES 1: FUNDAMENTOS Y AUTOMATIZACIÓN VISUAL (Make / Integromat)
-------------------------------------------------------------------------------
- SEMANA 1: Módulos y Triggers
  * Temas: Estructura de datos JSON básica, Webhooks, Triggers vs Actions.
  * Cursos: Make Academy (Foundation Course Level 1).
  * Meta: Crear una automatización que capture un correo y guarde los datos en Google Sheets/Airtable.

- SEMANA 2: Enrutamiento y Filtrado
  * Temas: Routers, Filtros, Iteradores y Agregadores.
  * Cursos: Make Academy (Foundation Course Level 2).
  * Meta: Construir un flujo que filtre correos importantes y los envíe a Telegram o Discord.

- SEMANA 3: APIs y Solicitudes HTTP
  * Temas: Verbos HTTP (GET, POST), Headers, Tokens de autenticación, API Keys.
  * Cursos: Make Academy (Intermediate).
  * Meta: Conectar una API pública externa (ej. clima, finanzas) a una hoja de cálculo.

- SEMANA 4: Proyecto Integrador Mes 1
  * Meta: Crear un bot de captura de prospectos automático para una tienda o servicio.

MES 2: INTEGRADOR DE IA Y PROMPT ENGINEERING
-------------------------------------------------------------------------------
- SEMANA 5: Fundamentos de APIs de IA (OpenAI / Anthropic)
  * Temas: Modelos (GPT-4o, Claude), Temperature, Tokens, System Prompts.
  * Cursos: DeepLearning.AI (ChatGPT Prompt Engineering for Developers).
  * Meta: Crear un script o nodo en Make que procese un texto largo y devuelva un resumen ejecutivo.

- SEMANA 6: Agentes y Clasificación de Datos
  * Temas: Extracción de entidades estructuradas (JSON output), Análisis de sentimiento.
  * Meta: Crear un sistema de atención que clasifique comentarios de clientes en "Positivo", "Queja" o "Venta".

- SEMANA 7: Automatización Avanzada con n8n
  * Temas: Instalación local/cloud de n8n, manejo de nodos comunitarios.
  * Cursos: Documentación y tutoriales oficiales de n8n.
  * Meta: Replicar en n8n los flujos aprendidos en Make.

- SEMANA 8: Proyecto Integrador Mes 2
  * Meta: Crear un "Agente de Ventas" por WhatsApp/Telegram que responda preguntas frecuentes usando IA.

MES 3: OFERTA COMERCIAL Y EVALUACIÓN
-------------------------------------------------------------------------------
- SEMANA 9: Empaquetado de Servicios
  * Temas: Definición de Oferta High-Ticket, Auditoría de procesos para Pymes.
  * Meta: Crear 2 propuestas comerciales tipo ficha técnica (Servicio de Atención con IA y Servicio de Automatización Operativa).

- SEMANA 10: Lanzamiento en Plataformas Freelance
  * Temas: Optimización de perfiles en Upwork/Fiverr, creación de portafolio visual.
  * Meta: Publicar 3 servicios (Gigs/Services) detallados en Upwork/Fiverr.

- SEMANA 11 Y 12: Consecución de los 3 Primeros Clientes
  * Meta: Enviar 20 propuestas personalizadas a Pymes o clientes internacionales para cerrar proyectos piloto.
